# Archive: do not print for the current board

These are superseded iterations and one-off test coupons, oldest first. Their parts do not fit the v7 board. The current files are in `../v7-board/` and `../pieces/`.

| Folder | What it was | Superseded by |
|---|---|---|
| `1-v5-open-wells/` | v5 board: lift-up lids over open stone wells, printed hinge pins (plates 00–04, 00 is its fit coupon) | the filament-pin hinge redesign |
| `2-hinge-experiments/` | hinge and fit test coupons (20, 21, 30, 50, 60, 70) and the abandoned print-in-place case halves (40, 41). Coupon 70 is the filament-pin fit test whose results set the current bore sizes | — (tests) |
| `3-pin-board/` | full board with 1.75 mm filament-pin hinges (plates 80–83) | v7, which removes the end lip, makes the folded ends flush and adds rubber-foot pockets |

The README one folder up from `print/` has the full design history, with each iteration's notes and export script.
