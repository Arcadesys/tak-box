# Unchecked physical acceptance

- [ ] Four leaf knuckle families turn independently on the same retained axle without binding.
- [ ] Board snaps engage with comfortable finger force, locate both halves flat and survive repeated use.
- [ ] Both drawers latch positively closed before any folding operation; no routine tools.
- [ ] Drawer access leaves the board stable and keeps pieces supported.
- [ ] Rear capstone hatch is captured and positively closed.
- [ ] Over-center case latch bears on a broad keeper, passes dead center and stops against a rigid stop; no closure pin or sleeve.
- [ ] Loaded shake/invert/carry tests retain all 42 flats and both capstones.
- [ ] Loaded opening and repacking never exposes an unsupported piece.
- [ ] Measure final hardware envelope against v16, including protrusions.
