# Hand test before case integration

- [ ] Print A and B on the supplied plate; record material/profile and revision.
- [ ] Remove any socket support without damaging the bearing shoulders.
- [ ] Both buttons click into their windows without tools or excessive force.
- [ ] Pulling without squeezing leaves both shoulders engaged.
- [ ] Squeezing both buttons releases comfortably; pressing only one stays locked.
- [ ] Repeat 50 cycles; inspect whitening, cracks, permanent bend and loss of retention.
- [ ] Integrate dedicated mount roots into both case halves, then test actual loaded-case shake, inversion and opening.

None of these physical tests has been completed. Digital release envelopes
do not establish spring strength or fatigue life.
