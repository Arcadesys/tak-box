# Optional captive-hinge trial

Open [captive-hinge-fit-check-CC2-PLA.3mf](captive-hinge-fit-check-CC2-PLA.3mf). Estimated print: **21 min 30 s / 3.80 g**. Keep both leaves together as the supplied single assembly, flat on the bed; do not auto-arrange or separate them.

This is a shortened pair of actual exported V22 hinge sections. Both opposed pivots are retained; only their spacing and connecting strips change. Main pins print captive, so no filament insertion or glue is required. The supplied project keeps supports on the build plate and uses no brim between the leaves.

After cooling, remove external support and gently work both joints through their range. Stop if a joint remains fused rather than forcing the thin trial strips. Check smooth folding, axial capture and cracks. Record observations before treating the joint as accepted.

The trial does not establish full-base warping, slider fit, capstone storage or loaded transport. Physical acceptance is unobserved.
