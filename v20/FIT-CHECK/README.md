# Optional V20 sliding-lid fit check

The full case is already prepared in ../PRINT. This optional print checks the new rail/button fit with less material.

Open **rail-and-catch-fit-check-CC2-PLA.3mf**. Estimate: **1 h 28 min / 33 g** including support and brims. It contains the front 65 mm of the actual V20 left base and lid, with unchanged rail, catch and pocket dimensions. Remove brim and any local support before testing.

Slide the lid into the base from the tab end, pressing its side button inward while it enters. Align the button with the wall opening and release. Check that a gentle pull cannot withdraw the lid until the button is pressed approximately 4.5 mm inward. It should slide smoothly without force, and the button should return without cracks or whitening. Keep the button pressed while it passes out of the rail.

The back of this cropped test is open. It does not test the full-length lid, rear end stop, hinges, capstones, warping or loaded transport. Its parts are not used in the full assembly. No physical result is recorded yet.
